# Full Review

Check the session environment before choosing the procedure. A nonempty
`FM2_TASK` or `FM2_PANEL` means this session belongs to the `fm` terminal
workflow: read [the CLI procedure](cli.md). Otherwise, read [the Codex app
procedure](app.md). Read only the selected procedure; the presence of a terminal
or an installed `fm` command alone does not select CLI mode.

The CLI review also reads the [shared review procedure](source.md).
