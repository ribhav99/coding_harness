---
name: prd-to-frds
description: Decomposes a PRD (Product Overview document) into a set of FRDs (Feature Requirements Documents), one per feature. Each FRD lands at `requirements/features/{feature-slug}/document.md` in the project repo. Use when a PRD covers multiple features that should be designed and built independently. For single-feature PRDs the operator may skip this and treat the PRD itself as the FRD.
